# Jean Bedel N'Guessan — Marketing, Branding & Communication 360°

Site portfolio et d'acquisition client : offres, séance découverte offerte, études de cas, vidéos YouTube, créations visuelles, documents stratégiques et réservation (WhatsApp / email).

## Structure

- `index.html` — la page complète
- `assets/js/main.js` — interactions (vidéos, galerie filtrable, formulaire) et animations (GSAP + ScrollTrigger)
- `assets/img/` — photos

## Voir le site en local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000

## Mise en ligne (GitHub Pages)

Settings → Pages → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)`.

## À compléter

Les éléments entre crochets `[...]` dans `index.html` : prix, dates, témoignages, liens YouTube / LinkedIn / Calendly, visuels de la galerie.
